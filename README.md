# Python Fundamentals: Data Structures & Conditions

## 📌 Overview

This assignment focuses on understanding and implementing fundamental Python concepts, including **Lists, Dictionaries, Sets, Operators, and Conditional Statements**.

The exercises demonstrate how Python data structures can be created, modified, accessed, and used for decision-making through practical examples.

## 🎯 Objectives 

* Understand list creation, modification, and access operations
* Work with dictionary key-value pairs
* Perform set operations such as union and intersection
* Understand uniqueness and unordered properties of sets
* Apply `if`, `elif`, and `else` conditional statements
* Use Python operators for decision-making
* Build a simple performance categorization program

## 🛠️ Concepts Covered

### 1. Lists

The assignment demonstrates:

* List creation
* `append()`
* `insert()`
* `remove()`
* `pop()`
* `extend()`
* `sort()`
* `max()`
* `min()`
* `sum()`
* List indexing
* List slicing
* Reverse-order access

### 2. Dictionaries

A `student_marks` dictionary is created to demonstrate:

* Dictionary creation
* Accessing values using keys
* Adding new key-value pairs
* Updating existing values
* `keys()`
* `values()`
* `items()`

### 3. Sets

The assignment demonstrates:

* Set creation
* Automatic removal of duplicate elements
* Understanding that sets do not support indexing
* Set union
* Set intersection

### 4. Conditional Statements

A **Performance Category Program** is implemented using `if`, `elif`, and `else`.

| Score Range    | Performance Category |
| -------------- | -------------------- |
| Greater than 7 | Above Average        |
| 4 to 7         | Average              |
| Less than 4    | Below Average        |

## 💡 Key Learning Outcomes

Through this assignment, I gained practical understanding of:

* How Python lists can be modified and accessed
* How dictionaries store data using key-value pairs
* How sets handle unique elements
* The difference between indexed and unordered data structures
* How conditional statements control program flow
* How operators can be combined to create logical conditions
